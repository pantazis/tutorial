# Static learning prototype

This directory is a local, no-build, `PROTOTYPE_ONLY` HTML/CSS/JavaScript workspace. It has no production authority and must not be treated as an application, schema, seed, migration, identity source, curriculum, translation authority, media approval, persistence layer, or security implementation.

## Open locally

1. Open `index.html` directly in a browser, including through a `file://` URL.
2. No server, installation, package manager, or build command is required.
3. Keep the `data/` and `assets/` directories beside `index.html` so all references remain local.

## Deterministic initial state

Every refresh returns to the same foundation overview. No selection is stored or transmitted. The synthetic fixture clock is fixed at `2026-09-18T12:00:00Z` and is not server time.

The page's core boundary notice, basic in-page navigation, local-asset explanation, and limitations remain readable when JavaScript is disabled. JavaScript currently provides only a factual availability message.

## Limitations

- All identities, course records, progress values, timestamps, scenarios, and outcomes in the copied JSON are synthetic fixtures.
- No API, database, identity provider, mail service, analytics service, tracker, or remote-media request is permitted.
- EL and EN courses are independent records, not translations and not shared progress records.
- The two local SVG files are neutral prototype fallbacks and are not production media approval.
- Future prototype behavior must remain simulated, deterministic, and reversible through clearly labeled prototype controls.
